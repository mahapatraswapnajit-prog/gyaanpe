Class 1 Maths Chapter 11: How Many Times?

NCERT Joyful Mathematics · Simple notes, key terms and practice questions

Equal groups can be counted by skip counting in 2s, 5s or 10s, or by adding the same number again. This is the start of multiplication.

Key concepts

👟Equal Groups

Groups with the same number are equal groups.

Example: 3 pairs of shoes: 2, 4, 6 shoes.

In real life: Socks come in pairs.

💡 Did you know? Count by skipping: 2, 4, 6.

🔁Skip Counting

Count in 2s, 5s or 10s to go fast.

Example: 2, 4, 6, 8; 5, 10, 15.

In real life: Counting coins.

💡 Did you know? Skip counting is the start of multiplication.

🖐️Hands and Fingers

Each hand has 5 fingers.

Example: 2 hands: 5, 10 fingers.

In real life: Counting fingers.

💡 Did you know? 3 children's hands: 6 hands.

🐞Legs

Animals have equal legs.

Example: 2 dogs have 4 + 4 = 8 legs.

In real life: Counting legs in a farm.

💡 Did you know? A spider has 8 legs.

➕Adding Again

Adding the same number again and again.

Example: 3 + 3 + 3 = 9.

In real life: Packets of sweets.

💡 Did you know? This is 3 times 3.
