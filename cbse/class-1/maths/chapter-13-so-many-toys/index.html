Class 1 Maths Chapter 13: So Many Toys

NCERT Joyful Mathematics · Simple notes, key terms and practice questions

We sort toys into groups, count them, show counts in picture charts and find which group has the most or least.

Key concepts

🧸Sorting

Sorting means putting same kinds together.

Example: Cars in one box, balls in another.

In real life: Tidying toys.

💡 Did you know? Sort by colour, shape or kind.

✏️Counting Toys

Count each group of toys.

Example: 4 cars, 3 balls, 5 dolls.

In real life: Toy box counting.

💡 Did you know? Tally marks help count.

📊Picture Chart

Pictures show how many.

Example: 🚗🚗🚗🚗 = 4 cars.

In real life: Class charts.

💡 Did you know? Charts make counting easy to see.

⚖️Most and Least

Find which group has the most or least.

Example: 5 dolls is the most.

In real life: Favourite toy votes.

💡 Did you know? Compare counts.

❓Answering Questions

Charts help answer questions.

Example: How many more dolls than balls? 2.

In real life: Reading charts.

💡 Did you know? Look carefully at the chart.
