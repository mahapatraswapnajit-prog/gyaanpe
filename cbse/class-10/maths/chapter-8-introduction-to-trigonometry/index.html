Class 10 Maths Chapter 8: Introduction to Trigonometry

NCERT Mathematics · Simple notes, key terms and practice questions

The chapter defines trigonometric ratios in a right triangle, gives values for 0°, 30°, 45°, 60° and 90°, and establishes and uses the three fundamental identities.

Key concepts

📐Trigonometric Ratios

In a right triangle, for angle A: sin A = opposite/hypotenuse, cos A = adjacent/hypotenuse, tan A = opposite/adjacent.

Example: Sides 3, 4, 5: sin A = 3/5, cos A = 4/5, tan A = 3/4.

In real life: Ramps and roofs use these ratios.

💡 Did you know? cosec, sec and cot are reciprocals of sin, cos and tan.

📋Special Angles

sin 30° = 1/2, sin 45° = 1/√2, sin 60° = √3/2; cos values reverse. tan 45° = 1; tan 60° = √3; tan 30° = 1/√3.

Example: sin 60° × cos 30° = 3/4.

In real life: Memorise the table — it's used everywhere.

💡 Did you know? sin 0° = 0, sin 90° = 1; tan 90° is not defined.

🔁Identities

sin²A + cos²A = 1; 1 + tan²A = sec²A; 1 + cot²A = cosec²A.

Example: If sin A = 3/5, cos A = 4/5.

In real life: Proving identities is a standard 3-mark question.

💡 Did you know? Identities hold for all valid angles.

🔄Reciprocal Relations

cosec A = 1/sin A; sec A = 1/cos A; cot A = 1/tan A = cos A/sin A.

Example: If tan A = 4/3, cot A = 3/4.

In real life: Simplifying expressions.

💡 Did you know? sin A × cosec A = 1.

🧠Proving Identities

Convert everything to sin and cos, simplify one side to equal the other.

Example: (1 − cos²A) cosec²A = sin²A × 1/sin²A = 1.

In real life: Clear steps earn full marks.

💡 Did you know? Never move terms across the equals sign in a proof.
