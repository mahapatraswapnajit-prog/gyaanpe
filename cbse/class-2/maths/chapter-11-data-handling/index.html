Class 2 Maths Chapter 11: Data Handling

NCERT Joyful Mathematics · Simple notes, key terms and practice questions

We collect information by asking questions, count with tally marks, show data in picture graphs, and find the most, the least and differences.

Key concepts

📋Collecting Information

We can ask friends questions and note answers.

Example: 'Which fruit do you like?'

In real life: Class surveys.

💡 Did you know? Answers are called data.

✏️Tally Marks

Tally marks help count. Every 5th line crosses the other 4.

Example: 𝍸 = 5.

In real life: Counting votes.

💡 Did you know? Tallies are quick.

🖼️Picture Graphs

Pictures show how many.

Example: 🍎🍎🍎 = 3 children like apples.

In real life: Wall charts.

💡 Did you know? Each picture stands for one.

⚖️Most and Least

Find the most and least liked.

Example: Mango 6, apple 3, banana 4: mango is most.

In real life: Favourite games.

💡 Did you know? Compare numbers.

❓Answering Questions

Use the graph to answer questions.

Example: How many more like mango than apple? 3.

In real life: Class discussions.

💡 Did you know? Read carefully.
