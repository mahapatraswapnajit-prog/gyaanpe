Class 3 Maths Chapter 10: Fun at Class Party!

NCERT Maths Mela · Simple notes, key terms and practice questions

At a class party we see patterns in decorations and numbers. Number patterns follow a rule, like adding 2 or 5. Arranging things in rows and making lists help plan, and number games make maths fun.

Key concepts

🎉Patterns

A pattern repeats in a fixed way.

Example: 🎈🎀🎈🎀🎈 — next is 🎀.

In real life: Party decorations use patterns.

💡 Did you know? Patterns can be in shapes, colours or numbers.

🔢Number Patterns

Numbers can grow by a rule.

Example: 2, 4, 6, 8 — add 2 each time.

In real life: Seat numbers follow patterns.

💡 Did you know? 5, 10, 15, 20 — add 5.

🍪Arranging Things

We can arrange things in rows and groups.

Example: 24 cups in 4 rows of 6.

In real life: Setting chairs for a party.

💡 Did you know? Same things can be arranged in many ways.

📋Making Lists

Lists help plan a party: items and how many.

Example: Plates 30, cups 30, balloons 15.

In real life: Teachers make class lists.

💡 Did you know? Tables make information clear.

🎲Fun Games

Games with numbers make maths fun.

Example: Guess the next number in a pattern.

In real life: Board games use counting.

💡 Did you know? Puzzles train our brains.

Key terms

TermMeaning
PatternSomething that repeats
RuleHow a pattern grows
ArrangementHow things are placed
RowLine from left to right
ListItems written one below another

Quick revision

  • 2, 4, 6, 8: add 2.
  • 5, 10, 15: add 5.
  • Patterns repeat by a rule.
