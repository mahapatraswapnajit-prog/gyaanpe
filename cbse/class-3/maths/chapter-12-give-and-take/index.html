Class 3 Maths Chapter 12: Give and Take

NCERT Maths Mela · Simple notes, key terms and practice questions

We use coins and notes to buy things. Adding prices gives the total, and when we pay more we get change. The same amount can be made in different ways, and saving small amounts regularly adds up.

Key concepts

💰Our Money

We use coins and notes: ₹1, ₹2, ₹5, ₹10 coins and ₹10, ₹20, ₹50, ₹100 notes.

Example: ₹50 + ₹20 = ₹70.

In real life: Shopping uses money.

💡 Did you know? 100 paise make 1 rupee.

🛒Buying Things

We add prices to find the total.

Example: Pencil ₹5 + eraser ₹3 = ₹8.

In real life: Grocery bills add prices.

💡 Did you know? Always check the total before paying.

🪙Getting Change

If we pay more, the shopkeeper gives change.

Example: Pay ₹20 for ₹15 item: change ₹5.

In real life: Bus fare change.

💡 Did you know? Change = money paid − price.

🔄Making Amounts

Many coins and notes can make the same amount.

Example: ₹10 = ₹5 + ₹5 = ₹2 + ₹2 + ₹2 + ₹2 + ₹2.

In real life: Counting a piggy bank.

💡 Did you know? Fewer coins are easier to carry.

🧾Saving

Saving means keeping money for later.

Example: Saving ₹5 each day for 4 days = ₹20.

In real life: Piggy banks help save.

💡 Did you know? Small savings grow big.

Quick revision

  • 100 paise = ₹1.
  • Change = paid − price.
  • Many ways make the same amount.
