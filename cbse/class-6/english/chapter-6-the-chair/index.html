Class 6 English Chapter 6: The Chair

NCERT Poorvi · Simple notes, key terms and practice questions

In the friendship unit, this chapter shows how friends understand and respect each other. It practises punctuation and the four types of sentences, and using quotation marks for speech.

Key concepts

🪑Theme: Friendship and Understanding

This chapter in the friendship unit is about how friends understand and respect each other.

Example: Small things like sharing a seat show care.

In real life: Making space for a friend.

💡 Did you know? Understanding others' feelings is called empathy.

❗Punctuation

Punctuation marks make meaning clear.

Example: Full stop (.), comma (,), question mark (?), exclamation mark (!)

In real life: Messages need correct punctuation.

💡 Did you know? 'Let's eat, Grandma!' vs 'Let's eat Grandma!'

❓Types of Sentences

Statements tell, questions ask, commands order, exclamations show feeling.

Example: 'The chair is old.' 'Is the chair old?' 'Sit down.' 'What a lovely chair!'

In real life: Signboards use commands.

💡 Did you know? Each type ends with a suitable mark.

💬Quotation Marks

Quotation marks show someone's exact words.

Example: Ria said, "Please sit here."

In real life: Stories with dialogue.

💡 Did you know? A comma comes before the opening quotes.

🤗Empathy

Empathy means understanding how others feel.

Example: Noticing a friend is sad and helping.

In real life: Comforting a classmate.

💡 Did you know? Empathy builds strong friendships.

Quick revision

  • Questions end with ?
  • Exclamations end with !
  • Quotes show exact words.
