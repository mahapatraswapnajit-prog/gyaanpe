Class 7 Maths Chapter 4: Expressions using Letter-Numbers

NCERT Ganita Prakash · Simple notes, key terms and practice questions

Letters can represent numbers, which lets us write general rules called formulas. Expressions with letter-numbers can be evaluated by substituting values. Like terms can be combined to simplify expressions without changing their value.

Key concepts

🔤Letter-Numbers

A letter like n or x can stand for a number that can change or is unknown.

Example: If a pen costs ₹p, then 3 pens cost ₹3p.

In real life: Formulas in science use letters like d for distance.

💡 Did you know? Using letters lets one rule work for many numbers.

📐Formulas

A formula is a rule written with letter-numbers.

Example: Perimeter of a square with side s is 4s.

In real life: Builders use formulas to find areas of rooms.

💡 Did you know? The same formula works for every square.

🧮Finding the Value

Put a number in place of the letter to find the value of the expression.

Example: If n = 5, then 2n + 3 = 13.

In real life: Finding the bill for any number of items uses substitution.

💡 Did you know? This is called substituting.

🧩Like Terms

Terms with the same letter part can be added or subtracted.

Example: 3a + 5a = 8a, but 3a + 5b cannot be combined.

In real life: Counting 3 boxes of a and 5 more boxes of a gives 8 boxes.

💡 Did you know? Numbers alone, like 7, are constant terms.

🔁Simplifying

Combine like terms to write an expression in a shorter form.

Example: 4x + 2 + 3x − 1 = 7x + 1.

In real life: Shortened rules are easier to use and share.

💡 Did you know? Simplifying does not change the value for any number.

Quick revision

  • Perimeter of a square = 4s.
  • 3a + 5a = 8a.
  • 2n means 2 × n.

Practice questions

Q1. If n = 5, what is the value of 2n + 3?

  1. 10
  2. 25
  3. 16
  4. 13
Show answerD) 13

Q2. The perimeter of a square with side s is

  1. s × s
  2. s + 4
  3. 2s
  4. 4s
Show answerD) 4s

Q3. Simplify: 3a + 5a

  1. 15a
  2. 35a
  3. 8
  4. 8a
Show answerD) 8a

Q4. Simplify: 4x + 2 + 3x − 1

  1. 7x + 3
  2. 7x + 1
  3. x + 1
  4. 9x
Show answerB) 7x + 1

  2. ₹6 + p
  3. ₹p − 6
  4. ₹6p
Show answerD) ₹6p
