Class 8 Maths Chapter 3: A Story of Numbers

NCERT Ganita Prakash · Simple notes, key terms and practice questions

The chapter follows how people moved from tally marks and Roman letters to bases and place value. It ends with the Indian ten-digit system with zero, which the whole world uses today.

Key concepts

🦴Early Counting

Long before digits, people counted by matching: one pebble, knot or notch for each object.

Example: A shepherd kept one pebble for each sheep to check that none was missing.

In real life: Tally marks are still used to count votes and scores.

💡 Did you know? Bones with carved tally notches thousands of years old have been found in Africa.

🏛️Roman Numerals

Romans used letters: I=1, V=5, X=10, L=50, C=100, D=500, M=1000. A smaller letter before a bigger one is subtracted.

Example: XLVII = 40 + 7 = 47.

In real life: Roman numerals still appear on clocks and in book chapters.

💡 Did you know? The Roman system had no symbol for zero, so big calculations were hard.

🔢The Idea of a Base

A base tells us how many units make the next group. We group in tens (base 10); computers use base 2.

Example: 1011 in base 2 = 8 + 0 + 2 + 1 = 11.

In real life: Time and angles (360°) still carry the base-60 idea.

💡 Did you know? The Babylonians used base 60, which is why an hour has 60 minutes.

📍Place Value

In a place-value system, the value of a digit depends on its position.

Example: In 5,372 the digit 3 stands for 300.

In real life: An abacus shows place value with beads on rods.

💡 Did you know? The Maya used base 20 and had their own sign for zero.

🇮🇳The Indian Number System

India developed ten digits 0–9 with place value and a true zero. Brahmagupta wrote rules for calculating with zero in 628 CE.

Example: With just ten digits we can write any number, however large.

In real life: The whole world uses this system today.

💡 Did you know? These numerals reached Europe through Arab scholars, so they are called Hindu-Arabic numerals.

  • Our everyday system is base 10 with digits 0–9.
  • The Babylonians used base 60.
  • Brahmagupta gave rules for zero in 628 CE.
