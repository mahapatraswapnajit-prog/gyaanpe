Class 9 Maths Chapter 4: Exploring Algebraic Identities

NCERT Ganita Manjari · Simple notes, key terms and practice questions

The chapter builds algebraic identities using geometric models — squares of two and three terms, cubes of sums and differences, and a³ + b³ + c³ − 3abc — and uses them to factorise and simplify expressions.

Key concepts

🟦Identities with Pictures

Identities like (a + b)² = a² + 2ab + b² can be seen by splitting a square into smaller squares and rectangles.

Example: A square of side a + b has parts a², b² and two ab rectangles.

In real life: Architects split areas into simple shapes.

💡 Did you know? An identity is true for all values of the variables.

🔺Three-Term Square

(a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca.

Example: (x + y + 1)² = x² + y² + 1 + 2xy + 2y + 2x.

In real life: Useful for areas of large squares split three ways.

💡 Did you know? Each pair appears twice.

🧊Cube Identities

(a + b)³ = a³ + b³ + 3ab(a + b); (a − b)³ = a³ − b³ − 3ab(a − b).

Example: (x + 2)³ = x³ + 6x² + 12x + 8.

In real life: A cube of side a + b splits into 8 blocks.

💡 Did you know? a³ + b³ = (a + b)(a² − ab + b²).

⭐A Special Identity

a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca). So if a + b + c = 0, then a³ + b³ + c³ = 3abc.

Example: If a = 1, b = 2, c = −3: 1 + 8 − 27 = −18 = 3 × 1 × 2 × (−3).

In real life: Puzzle contests love this identity.

💡 Did you know? Shortcuts like this save long calculations.

🧩Factorisation

Factorising writes an expression as a product, often using identities or splitting the middle term.

Example: x² − 9 = (x + 3)(x − 3); x² + 5x + 6 = (x + 2)(x + 3).

In real life: Factorising helps solve equations quickly.

💡 Did you know? (x² − 4)/(x − 2) simplifies to x + 2 when x ≠ 2.

Quick revision

  • (a + b)² = a² + 2ab + b².
  • If a + b + c = 0 then a³ + b³ + c³ = 3abc.
  • x² − 9 = (x + 3)(x − 3).

Practice questions

Q1. (a + b + c)² = ?

  1. a² + b² + c² + 2ab + 2bc + 2ca
  2. 2a + 2b + 2c
  3. a² + b² + c² + ab + bc + ca
  4. a² + b² + c²
Show answerA) a² + b² + c² + 2ab + 2bc + 2ca

Q2. (x + 2)³ = ?

  1. x³ + 6x² + 12x + 8
  2. x³ + 8
  3. x³ + 2x² + 4x + 8
  4. x³ + 6x + 8
Show answerA) x³ + 6x² + 12x + 8

Q3. x² − 9 factorises as

  1. (x − 9)(x + 1)
  2. (x + 9)(x − 1)
  3. (x − 3)²
  4. (x + 3)(x − 3)
Show answerD) (x + 3)(x − 3)

Q4. 103² using an identity equals

  1. 10609
  2. 1069
  3. 10309
  4. 10900
Show answerA) 10609

Q5. a³ + b³ = ?

  1. (a + b)(a² − ab + b²)
  2. (a − b)(a² + ab + b²)
  3. (a + b)³
  4. a² + b²
Show answerA) (a + b)(a² − ab + b²)
