Class 9 Maths Chapter 7: The Mathematics of Maybe: Introduction to Probability

NCERT Ganita Manjari · Simple notes, key terms and practice questions

The chapter introduces probability: random experiments, outcomes and events, theoretical and empirical probability, tree diagrams for multi-step experiments, and the ideas of sure and impossible events.

Key concepts

🎲Experiments and Outcomes

A random experiment has outcomes we cannot predict for sure. An event is a set of outcomes.

Example: Rolling a die: outcomes 1, 2, 3, 4, 5, 6. 'Getting an even number' is an event.

In real life: Weather forecasts give chances, not certainties.

💡 Did you know? Each toss of a fair coin is independent of earlier tosses.

➗Theoretical Probability

P(event) = number of favourable outcomes ÷ total number of equally likely outcomes.

Example: P(even on a die) = 3/6 = 1/2.

In real life: Lucky draws use probability.

💡 Did you know? Probability is always between 0 and 1.

📊Empirical Probability

Empirical probability = number of times the event happened ÷ number of trials.

Example: 56 heads in 100 tosses → empirical P(head) = 0.56.

In real life: Cricket stats estimate a batter's chance of scoring.

💡 Did you know? With more trials, empirical probability gets closer to the theoretical value.

🌳Tree Diagrams

A tree diagram lists all outcomes of a multi-step experiment branch by branch.

Example: Two coins: HH, HT, TH, TT → P(two heads) = 1/4.

In real life: Planning outfits: 3 shirts × 2 trousers = 6 combinations.

💡 Did you know? Multiply along branches for 'and' events.

✅Sure and Impossible

A sure event has probability 1; an impossible event has probability 0. P(not E) = 1 − P(E).

Example: P(7 on a die) = 0; P(not 6) = 5/6.

In real life: An insurer uses probabilities to set premiums.

💡 Did you know? Probabilities of all outcomes add up to 1.

Key terms

Quick revision

  • P(E) = favourable ÷ total outcomes.
  • 0 ≤ P(E) ≤ 1.
  • P(not E) = 1 − P(E).
